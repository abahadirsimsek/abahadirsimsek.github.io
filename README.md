# abahadirsimsek.github.io

Sade, statik ve GitHub Pages uyumlu akademik kişisel site.

## Dosyalar

- `index.html` — ana akademik profil
- `tools.html` — tarayıcı içinde çalışan Python araçları
- `tools.py` — PyScript/Pyodide ile çalışan örnek istatistik aracı
- `assets/style.css` — ortak tasarım
- `cv.pdf` — sizin eklemeniz gereken CV dosyası

## GitHub'a yükleme

Depoda **Add file → Upload files** yolunu açın ve bu klasördeki dosyaları yükleyin.
`assets` klasörünün yapısını koruyun.

## İlk düzenlenecek alanlar

`index.html` içinde:
1. Ünvan, kurum ve bölüm
2. Kısa akademik profil
3. Araştırma temaları
4. Seçilmiş yayınlar
5. Projeler
6. Dersler
7. E-posta
8. Google Scholar, ORCID, GitHub ve kurumsal profil bağlantıları

## CV

Kendi CV dosyanızı `cv.pdf` adıyla depo köküne ekleyin.

## Python aracı

`tools.html`, PyScript'i CDN üzerinden yükler. Hesaplama ziyaretçinin tarayıcısında gerçekleşir.
API anahtarı, parola veya gizli veri bu dosyalara eklenmemelidir.
